AM programming language

Created by Anuj Mishra

AM is a free programming language that looks exactly like Python, runs every Python library, and fixes common Python bugs automatically. If you know Python, you already know AM.

pip install am-language VS Code extension GitHub

Get started in one minute

You need Python 3.9 or newer.

pip install am-language

Save this as hello.am:

name = "World"
print("Hello " + name)

Run it:

am hello.am

Why AM?

Nothing new to learn

AM uses Python syntax, so every Python tutorial works for AM too.

Every Python library

numpy, pandas, requests, Django: anything you can pip install works in AM.

Fewer bugs

AM fixes or warns about the Python mistakes that trip up beginners most.

Easy error messages

Instead of a long traceback: the line, what went wrong, and how to fix it.

Error messages that help

Error in main.am, line 2:
    print("Age: " + age)

TypeError: can only concatenate str (not "int") to str
Hint: You are mixing text and numbers. Use str(x) to turn a number
into text, or int(x) / float(x) to turn text into a number.

About the creator

The AM programming language was created by Anuj Mishra (GitHub: chaman640). The goal of AM: a language that is as easy to learn as possible, fits into the Python world, and removes the Python mistakes that confuse beginners.

Questions

Who created AM?

AM was created by Anuj Mishra.

Is AM free?

Yes. AM is free and open source under the MIT License.

Can I use my Python code and libraries?

Yes. AM code is Python code, and AM files can import Python modules. Python can import .am files too, after import amlang.

How does it work?

AM reads your code with Python's own parser, fixes the risky patterns, and runs it with Python. There is no separate runtime.
